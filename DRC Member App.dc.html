WHAT THE QR CARRIES
{{ payload }}

Version, member ID, name and pace group, signed. The scanner reads it with no signal and queues the check-in until it reconnects. The ID is the only thing the backend needs — name and pace are there so the screen can greet a runner offline.

THE DATA MODEL

Four tables: members, events, rsvps, check-ins. Runs attended, streak and milestones are all counted off the check-ins table, so nothing is entered by hand.

BUILDING IT FAST

Supabase gives you email magic links, the database and row-level security out of the box. Captains get an admin role; the kiosk runs one shared device account.

SAMPLE DATA
